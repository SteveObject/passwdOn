# passwdOn

passwdOn 是适用于 Microsoft Edge 的本地密码管理扩展。同一个账号可以在 `https://crm.example.com` 和 `https://git.example.com` 使用不同密码。同一个站点也可以保存多个账号。

## 在 Edge 中安装

1. 打开 `edge://extensions`，开启「开发人员模式」。
2. 点击「加载解压缩的扩展」，选择项目中的 `extension` 文件夹。
3. 在工具栏打开 passwdOn，创建至少 12 个字符的主密码。
4. 点击「管理密码库」，新建分组或直接新增账号。每条记录可填写站点地址、账号、密码、显示名称和分组。

## 填充与管理

- 在登录页打开 passwdOn，或按 `Alt+Shift+P`。扩展会识别当前页面的登录字段，并列出该站点的已存账号。选择一条记录后，检查填入的内容并自行提交。
- 匹配使用协议、完整主机名和端口，路径自动忽略。不同子域名或端口各自保存。地址需带 `https://` 或 `http://`，支持 HTTPS 的站点应使用 HTTPS 地址。
- 遇到多个可识别的登录区域时，先点击目标输入框，再打开扩展。先输账号、后输密码的页面可在每一步各打开一次扩展。账号步骤需要网页提供标准的 `autocomplete="username"` 标记。
- 密码库支持搜索、编辑、删除和移动账号。删除分组会将其中的账号移到「未分组」。
- 如快捷键被占用，可在 `edge://extensions/shortcuts` 中修改。

识别范围是当前标签页的顶层网页，包括常见的账号和密码输入框。iframe、Shadow DOM 和自定义控件可能需要手动填写。第三方登录跳转后，记录应使用实际登录页的站点地址。

## 数据与锁定

密码库通过 PBKDF2-SHA-256 派生密钥，使用 AES-256-GCM 加密后保存到当前浏览器配置文件。解锁状态只在当前浏览器会话中保留，打开扩展或操作密码库时续期 10 分钟。可以手动锁定。扩展只在你打开它时取得当前标签页的临时访问权限。

本版的记录需要手动添加，保存在本机。请保管主密码，卸载扩展或清除扩展数据会删除密码库。目前尚无密码找回、导入导出或跨设备同步。

## 开发与验证

扩展无需安装依赖或构建。修改文件后，在扩展管理页点「重新加载」。

- `node tests/browser.mjs` 使用支持 DevTools 扩展测试命令且允许加载未打包扩展的 Chromium 运行端到端检查。需要 Node.js 22+。可通过 `CHROMIUM` 指定浏览器可执行文件。
- `node tests/browser.mjs --simulate-extension` 在 Chromium 中运行同一组页面流程，并模拟扩展 API。适合无法加载未打包扩展的环境。
